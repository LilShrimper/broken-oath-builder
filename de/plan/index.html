Read the game data from your own install

The sim can read skills, items and the passive tree straight from your own copy of Broken Oath. Nothing is uploaded: every file is read in this browser tab.

  1. Click Pick the Data folder.
  2. Go to your game folder, usually C:\Program Files (x86)\Steam\steamapps\common\Broken Oath Playtest (in Steam: right-click the game › Manage › Browse local files).
  3. Open BrokenOath, select the Data folder and confirm. Your browser may ask whether to "upload" the files: that only means this page may read them.

The page remembers your files in this browser while they are newer than the site's data; Use the site's data at the top switches back.

        IMPORT A LOADOUT

        Load a build code

        Paste a code copied from the passive skill tree (BO1.), a saved build plan (BOP1.) or a link from the ItemDatabase planner (broked-db.pages.dev/planner#b=…, or an older broked-db.vercel.app/b/… link, with its rolled items). The code is decoded in this browser.

        Also count

        Tick other skills for the optimizer, Plan and the node values to weigh too. Weight 1 = as much as the main skill, 0.5 = half. Each skill counts by its own % change, so a weak skill is not drowned out by a strong one.

        Each skill added here is simmed for every option tried, so the tree optimizer, Plan, node values and Gear Set Sim get slower: about one more full run per skill.

        Click a node to take it (the shortest path is added) or to refund it (nodes that lose their connection go too). Hover for its stats and what it does to the selected skill's DPS against the enemy set on the left. Right-click a node (on a touch screen: tap it, then Never take) to mark it never take: it gets a red cross, and Optimize, Plan and the node values skip it and never path through it. Right-click again to allow it. Heat map: brighter green = more DPS per point spent. Diamonds are Oath Masteries: one opens when you take any of its notables, then click it to swear one of its Oaths. Changes here apply to the Damage tab until you reset or switch character.

        How to load your saves

        Watch the walkthrough, then open the Windows folder picker below.

        1. Copy the save path, then click Open SaveGames folder.
        2. Click the address bar at the top of the picker. Paste the path with Ctrl+V, then press Enter.
        3. Stay inside SaveGames and click Select Folder. If the browser asks to upload, confirm to let this page read the files.
        %LOCALAPPDATA%\BrokenOath\Saved\SaveGames

        All characters in the folder are loaded. Your saves are read in this browser; nothing is uploaded.
