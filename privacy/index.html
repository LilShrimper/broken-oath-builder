Privacy Policy

How Broken Oath Builder handles your files, shared builds and reports.

Last updated 11 November 2026

Your files stay on your device

Save files, game data, screenshots and the game log you open are processed in your browser. The site does not upload those files. The Save Creator edits eligible offline saves in your browser and gives you a download; you decide whether to copy it into the game folder.

Browser storage

The builder uses local storage and browser storage for loaded character summaries, plans, settings and remembered folder access where supported. This lets you return to your work on the same device. Use the builder's Reset control to remove loaded characters and plans, or clear this site's browser data to remove its saved settings and permissions too. Export anything you want to keep first.

Shared builds

Choosing Copy share link sends an encoded build to our Cloudflare share service so it can create a short link. The build can include the character name, class, level, equipment, skills and passive tree. Anyone with the link can open it; treat it as public. It does not include your original save file or Steam ID. Stored short links have no automatic expiry. A long build code or link can also contain the build itself, so anyone you give that code or link to can read it.

Problem reports and fight checks

Sending a report submits the text you write, the current tab and game-data version, and any fight-check summary shown in the form. A build is attached only if you tick that option; attaching it creates a share link with the access described above. Fight log excerpts are optional too: the form previews the selected combat lines with identifying details removed. The full game log is never uploaded. Review your text and attachments before sending and leave out personal information.

Reports are stored in Cloudflare KV for up to 180 days, unless removed earlier, and are accessible to the site owner through an authenticated tool. Attached build links are stored separately and do not expire with the report. To limit spam, the service derives a daily hash from your IP address and keeps a report counter under that hash for one hour. It does not store your raw IP address with your report.

Hosting, analytics and other services

  • GitHub Pages hosts the public site. GitHub and Cloudflare process network request information, including IP addresses, to deliver and protect their services. See GitHub's privacy statement and Cloudflare's privacy policy.
  • The builder's public pages use GoatCounter for visitor statistics, including page views, referrers and browser or device information. GoatCounter does not use tracking cookies. See GoatCounter's privacy information. These legal pages do not load the counter.
  • The support button loads a Buy Me a Coffee script. Using the donation service is optional and subject to its privacy policy. The builder does not receive payment-card details.
  • Reading text from a screenshot downloads Tesseract software and language data from external delivery services such as jsDelivr. Image processing stays in your browser.
  • The Ladder displays the game's public API data through our Cloudflare cache. The builder does not upload your local saves to the ladder. Importing a Broked DB short link asks our service to retrieve that shared build from Broked DB.

The builder does not require an account, sell your data or set advertising cookies. External services have their own data-handling practices.

Your choices and requests

You can use the tools without sharing a build or sending a report. To ask about access, correction or removal of a stored report or short link, use the contact page. Include the report reference or share link so the owner can find it. Clearing browser data does not delete information already sent to the share or report service. Copies other people have made cannot be recalled.

If this policy changes, the update date on this page will change.
