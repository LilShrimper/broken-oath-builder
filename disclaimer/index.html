Playtest data and calculated results

The game is changing during its playtest. The site's bundled data may lag behind a patch, and the simulator does not model every mechanic or combat situation. Tooltips, developer notes and fight checks help verify the model, but a calculated result is an estimate rather than a guarantee.

Offline save downloads

The Save Creator produces a modified offline save for you to download. It does not replace files on your computer. Back up your original file and check that you selected the correct offline character before using a download.
