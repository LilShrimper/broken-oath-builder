Read the game data from your own install

The sim can read skills, items and the passive tree straight from your own copy of Broken Oath. Nothing is uploaded: every file is read in this browser tab.

  1. Click Pick the Data folder.
  2. Go to your game folder, usually C:\Program Files (x86)\Steam\steamapps\common\Broken Oath Playtest (in Steam: right-click the game › Manage › Browse local files).
  3. Open BrokenOath, select the Data folder and confirm. Your browser may ask whether to "upload" the files: that only means this page may read them.

The page remembers your files in this browser while they are newer than the site's data; Use the site's data at the top switches back.
